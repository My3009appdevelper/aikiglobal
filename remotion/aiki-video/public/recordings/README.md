# Grabaciones de Aiki

Agrega aquí las grabaciones reales. Usa orientación vertical para todas las pantallas: cada grabación aparecerá dentro de un mockup de teléfono. Mantén el mismo contenido protagonista durante todo el recorrido.

Nombres esperados:

- `user-explore.mp4`: Explorar y selección de una meditación.
- `user-my-space.mp4`: Mi espacio, progreso y contenidos guardados.
- `admin-create-content.mp4`: listado administrativo y apertura de Nuevo contenido.
- `admin-edit-content.mp4`: edición de portada, título, descripción y material multimedia.
- `user-subscriptions.mp4`: plan activo, beneficios y administración de la suscripción.
- `user-streaks.mp4`: contador de días, calendario semanal y continuidad de la práctica.
- `admin-notification.mp4`: título, mensaje, audiencia, destino, vista previa y envío.
- `user-notification.mp4`: aviso recibido, inbox y apertura del aviso.

Recomendaciones de captura:

- Ocultar datos personales, tokens, correos y UUIDs.
- Usar una cuenta de demostración con datos consistentes.
- No cambiar el contenido protagonista entre escenas.
- Grabar cada flujo completo, dejando unos segundos quietos antes y después de cada acción.
- Para las pantallas administrativas, priorizar una captura vertical o un encuadre que conserve el formulario completo dentro del teléfono.
- Para push, grabar solo después de validar la entrega en el entorno de demostración.
